# 東京駅乗り換え3Dアプリ

東京駅の乗り換えルートを、3D模型と高速POVで確認できる静的Webページです。

- 公開ページ: https://kokazkoko.github.io/norikae-warp/
- 地図データ: © OpenStreetMap contributors（ODbL）
- 経路・階・改札の情報は地図データからの推定を含みます。所要時間は目安です。

## データの補正
`tools/fix_station.py` で、埋め込みデータを公式構内図（東京駅構内MAP 1F/B1 2026年8月版、JR東海 東京駅新幹線構内図、らくらくおでかけネット構内図）と照合して補正しています（新幹線乗換口の階、京葉線連絡通路、丸の内地下、中央線ホーム3F、改札名・丸の内北口/南口改札など）。

## ベビーカールートとお店の表示
- ベビーカー・車いすルート（ピンク）: 階段・エスカレーターを使わず、エレベーターと通路だけで移動。OSM にエレベーターが無い段差には「位置は推定」のエレベーターを補っています（`tools/data/elevators.json`）。
- お店: OSM の店舗（`tools/data/shops.json`）と、グランスタ東京・東京駅一番街などの店舗ゾーン通路に、半透明の店先を表示。
